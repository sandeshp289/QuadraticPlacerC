# QuadraticPlacerC

Description:

    Quadratic Placer in C/C++

Input Files:

    qp_placer_8x8.c                  : C/C++ code

    toy1                             : Input file (for e.g. toy1) containing the placement problem in text format

Output Files:

    toy1.3qp.output                  : Output file to specify each placement output in text format

   
Compilation:

    g++ qp_placer_8x8.c
    
Execution:

    ./a.out toy1
